# Қауіпсіздік сканерлеу нәтижелері

## 1. Мақсаты

Tour Request System жобасының бастапқы кодын және Git репозиторийінің тарихын қауіпсіздік тұрғысынан тексеру. Тексеру үшін Trivy және Gitleaks құралдары Docker контейнерлері арқылы қолданылды.

## 2. Trivy нәтижелері

**Құрал:** Trivy  
**Тексеру түрлері:** Vulnerabilities, Misconfigurations, Secrets  
**Нысан:** Tour Request System репозиторийінің жергілікті көшірмесі

Тексеру нәтижесінде:

- Secrets сканері тексерілген файлдардан құпия деректерді анықтаған жоқ.
- Language-specific files саны: 0.
- Vulnerability және Misconfiguration сканерлеріне сәйкес келетін қолдау көрсетілетін файлдар табылмады.

**Қорытынды:** Trivy құпия деректер бойынша мәселе анықтаған жоқ. Алайда тәуелділіктер мен конфигурациялар бойынша толық қауіпсіздік қорытындысын жасауға жеткілікті деректер болмады.

## 3. Gitleaks нәтижелері

**Құрал:** Gitleaks  
**Тексеру нысаны:** Git репозиторийінің тарихы

| Көрсеткіш | Нәтиже |
|---|---|
| Тексерілген коммиттер | 44 |
| Тексерілген деректер көлемі | 152.17 KiB |
| Табылған құпия деректер | 0 |
| Қорытынды хабарлама | no leaks found |

**Қорытынды:** Git тарихын сканерлеу барысында құпиясөздердің, API токендерінің және басқа құпия деректердің белгілі үлгілеріне сәйкес келетін ақпарат анықталмады.

## 4. Ұсыныстар

Жобаға жаңа код пен тәуелділіктер қосылған сайын Trivy және Gitleaks тексерулерін қайталау қажет. Құпия деректерді репозиторийге енгізбеу, оларды қорғалған орта айнымалыларында сақтау және қауіпсіздік тексерулерін CI/CD процесіне енгізу ұсынылады.

## 5. Жалпы қорытынды

Екі құралмен жүргізілген бастапқы тексерулер барысында құпия деректердің таралу белгілері анықталған жоқ. Бұл нәтиже жобаның толық қауіпсіз екеніне кепілдік бермейді, сондықтан қауіпсіздік бақылауы келесі әзірлеу кезеңдерінде жалғасуы тиіс.
