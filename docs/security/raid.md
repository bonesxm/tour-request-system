# ЛЗ 7. Реестр рисков проекта

Проект: Система управления заявками клиентов турагентства
## Pre-mortem: ықтимал тәуекелдер


## Pre-mortem: жобаның ықтимал тәуекелдері

Төменде турагенттік клиенттерінің өтінімдерін басқару жүйесіне қатысты алдын ала анықталған 20 ықтимал тәуекел берілген. Бұл тізім командалық талқылауда нақтыланады.

| № | Тәуекел | Ықтимал салдары |
|---|---|---|
| 1 | Тапсырыс беруші уақытында жауап бермейді | Талаптарды келісу кешігеді |
| 2 | Жоба талаптары жиі өзгереді | Қосымша жұмыс көлемі пайда болады |
| 3 | Команда MVP-ді уақытында аяқтамайды | Жобаны тапсыру мерзімі кешігеді |
| 4 | Тапсырмалардың күрделілігі дұрыс бағаланбайды | Жоспарланған уақыт жеткіліксіз болады |
| 5 | Өтінімді сақтау кезінде қате пайда болады | Клиент өтінімі жоғалуы мүмкін |
| 6 | Деректер базасындағы ақпарат жоғалады | Клиенттердің мәліметтері қалпына келмейді |
| 7 | Клиенттердің жеке деректері сыртқа таралады | Құпиялылық бұзылады |
| 8 | Жүйеге рұқсатсыз кіру орын алады | Бөгде адам өтінімдерді көре алады |
| 9 | Менеджердің құпиясөзі бұзылады | Аккаунтқа бөгде адам кіреді |
| 10 | Пайдаланушы рөлдері дұрыс шектелмейді | Құқықсыз әрекеттер орындалады |
| 11 | Бағдарламалық кітапханаларда осалдық болады | Жүйенің қауіпсіздігі төмендейді |
| 12 | GitHub репозиторийіне құпия кілт жарияланады | Құпия ақпаратқа қол жеткізілуі мүмкін |
| 13 | Сервер қолжетімсіз болады | Менеджерлер өтінімдермен жұмыс істей алмайды |
| 14 | Резервтік көшірме жасалмайды | Ақау кезінде деректерді қалпына келтіру қиындайды |
| 15 | Деректерді көшіру кезінде қате болады | Өтінімдер толық көшірілмейді |
| 16 | Өзгерістер тарихы дұрыс сақталмайды | Өтінімнің кім өзгерткенін анықтау қиындайды |
| 17 | Іздеу функциясы қате жұмыс істейді | Қажетті өтінім табылмайды |
| 18 | Тестілеу жеткіліксіз жүргізіледі | Маңызды қателер анықталмай қалады |
| 19 | Пайдаланушы нұсқаулығы дайын болмайды | Жүйені қолдану қиындайды |
| 20 | Интерфейс пайдаланушыларға түсініксіз болады | Менеджерлер жұмыс кезінде қателеседі |
