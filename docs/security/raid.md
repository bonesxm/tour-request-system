# ЛЗ 7. Реестр рисков проекта

Проект: Система управления заявками клиентов турагентства
## Pre-mortem: ықтимал тәуекелдер

Команда жобаның сәтсіз аяқталуы мүмкін
себептерін алдын ала қарастырды.

| № | Тәуекел | Салдары |
|---|---|---|
| 1 | Тапсырыс беруші уақытында жауап бермейді | Жоба кешігеді |
| 2 | Талаптар жиі өзгереді | Қайта өңдеу қажет болады |
| 3 | Клиент деректері жоғалады | Маңызды ақпарат жоғалады |
| 4 | Жүйеге бөгде адам кіреді | Деректердің құпиялығы бұзылады |
