# Дербес деректерді қорғау талаптарына сәйкестік чек-парағы

## 1. Мақсаты

Бұл құжат Tour Request System жобасында клиенттердің дербес деректерін жинау, өңдеу, сақтау және қорғау талаптарын бағалау үшін әзірленді.

**Нормативтік негіз:** Қазақстан Республикасының 2013 жылғы 21 мамырдағы №94-V «Дербес деректер және оларды қорғау туралы» Заңы.

## 2. Өңделетін деректер

Жобада келесі деректерді өңдеу жоспарланады:

- Клиенттің аты-жөні;
- Байланыс телефоны;
- Электрондық пошта мекенжайы;
- Туристік өтінімнің мазмұны мен мәртебесі;
- Өтінімді өңдеген менеджер туралы ақпарат.

## 3. Сәйкестік чек-парағы

| № | Тексеру талабы | Мәртебесі |
|---|---|---|
| 1 | Деректерді жинау мақсаты анықталған | Жоспарланған |
| 2 | Клиенттің келісімін алу немесе өзге заңды негізді анықтау | Тексеру қажет |
| 3 | Артық дербес деректерді жинамау | Жоспарланған |
| 4 | Деректерді Қазақстан аумағында сақтау | Тексеру қажет |
| 5 | HTTPS арқылы деректерді қорғау | Жоспарланған |
| 6 | Менеджер мен әкімшінің құқықтарын RBAC арқылы бөлу | Жоспарланған |
| 7 | Құпиясөздерді қауіпсіз хэштеу | Жоспарланған |
| 8 | Деректерді сақтау мерзімін анықтау | Тексеру қажет |
| 9 | Деректерді жою және түзету тәртібін белгілеу | Жоспарланған |
| 10 | Пайдаланушы әрекеттерін аудит журналында тіркеу | Жоспарланған |
| 11 | Құпия деректерді Git репозиторийіне енгізбеу | Gitleaks тексеруінде белгі анықталмады |
| 12 | Автоматтандырылған шешімдер мен AI қолданылуын бағалау | Тексеру қажет |

## 4. Жауапкершілік

**PM/BA:** дербес деректерді өңдеу талаптарын анықтау және құжаттау.

**Backend Developer:** авторизация, рөлдер, деректерді қорғау және аудит механизмдерін әзірлеу.

**Frontend Developer:** пайдаланушыға келісім және құпиялылық туралы ақпаратты көрсету.

**QA/DevOps:** қауіпсіздік тесттерін жүргізу және конфигурацияларды тексеру.

## 5. Қорытынды

Жобада дербес деректерді қорғауға қатысты негізгі талаптар анықталды. Қазіргі кезеңде олардың басым бөлігі жоспарланған немесе қосымша тексеруді қажет етеді. Сондықтан бұл құжат толық заңнамалық сәйкестікті растау емес, жобаны әзірлеу барысында қолданылатын бақылау тізімі болып табылады.
