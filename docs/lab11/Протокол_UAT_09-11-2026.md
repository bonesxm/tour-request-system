## Дополнительные результаты автоматизации и мониторинга от 10.11.2026

- **API и CI:** в `tests/test_app.py` есть 6 тестовых функций. GitHub Actions run #11 для PR #38 прошёл успешно; шаги API tests и проверки синтаксиса завершены успешно. Результат: [GitHub Actions](https://github.com/bonesxm/tour-request-system/actions/runs/42680152861). SHA CI не сверялся с SHA Render.
- **Покрытие:** по сообщению тестировщика запускалась команда `py -3.14 -m pytest -q --cov=app --cov-report=term-missing tests/test_app.py`; в сводке команды указано 84%. Отдельный вывод coverage в новых скриншотах отсутствует.
- **Playwright:** `py -3.14 -m pytest -v tests/e2e/test_browser.py` — 1 тест пройден за 1,90 секунды.
- **k6:** снимок сделан во время прогона: 10 VU, 600 проверок, 600 успешных, 0 ошибок, p95 10,55 мс. Внизу экрана указано, что тест ещё выполнялся на отметке 1:00 из запланированных 1:30; финальная сводка не предоставлена.
- **Uptime Kuma:** монитор показывает текущий статус «Доступен»; на снимке также есть запись об ответе HTTP 503. Поэтому записываем оба факта и не заявляем, что сбоев за период не было.
- **Сверка 503 с Render:** снимки Application Logs и Events показывают успешный запуск/ответы приложения и успешные деплои, но Events не является журналом HTTP-запросов. В логах на снимке нет связанной записи 503; это не устанавливает причину и не доказывает отсутствие краткого события. Ответ Uptime Kuma оставлен как несопоставленное предупреждение, не как подтверждённый инцидент.

## Наблюдения по данным

1. CSV содержит три тестовые заявки с ID #1–#3. Значения статусов и агрегаты панели согласуются.
2. В поле телефона заявок #1 и #2 в CSV виден завершающий символ «л» (`+7 700 000 00 00л`). Это значение присутствует в тестовой выгрузке. Если оно случайное, при следующем редактировании исправить тестовые данные; дефектом системы считать только при наличии требования к формату телефона.
3. #3 содержит email `admin@tour.local` и пустые опциональные поля. Это демонстрационный адрес системы, не реальный клиентский email.
4. Все три тестовые записи оставлены в стенде.
