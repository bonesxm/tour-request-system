

\# AI Smart Request — инструкция по запуску



\## О проекте



TourFlow — система управления туристическими заявками

с интегрированной функцией искусственного интеллекта.



AI Smart Request автоматически извлекает из сообщения клиента:

\- Город отправления

\- Город назначения

\- Бюджет поездки

\- Количество взрослых

\- Количество детей

\- Приоритет заявки



Используется локальная модель Qwen 2.5 3B через Ollama.



\## 1. Требования



\- Python 3.11 или новее

\- Visual Studio или другой редактор кода

\- Ollama

\- Модель qwen2.5:3b



\## 2. Установка зависимостей



Откройте терминал в папке проекта и выполните:



python -m pip install -r requirements.txt



\## 3. Установка искусственного интеллекта



Скачайте Ollama:

https://ollama.com/download/windows



После установки выполните:



ollama pull qwen2.5:3b



Убедитесь, что Ollama запущена.



\## 4. Запуск сайта



В терминале выполните:



python -m uvicorn app:app --reload



Откройте в браузере:



http://127.0.0.1:8000



\## 5. Проверка AI Smart Request



1\. Войдите в систему TourFlow.

2\. Откройте форму «Новая заявка».

3\. Введите сообщение клиента:



Срочно! Хотим вылететь из Астаны в Дубай,

2 взрослых и 1 ребёнок, бюджет 800 тысяч тенге.



4\. Нажмите «Заполнить с помощью ИИ».

5\. Проверьте автоматически заполненные поля.



Ожидаемый результат:

\- Отправление: Астана

\- Направление: Дубай

\- Бюджет: 800000

\- Взрослые: 2

\- Дети: 1

\- Приоритет: Срочно



Перед сохранением пользователь должен проверить данные.



\## 6. Тестирование модели



Проверка одной заявки:



python ai\_module/ai\_model.py



Тестирование Baseline:



python ai\_module/evaluate.py



Пересчёт метрик Zero-shot и Few-shot:



python ai\_module/calculate\_metrics.py



\## 7. Результаты эксперимента



Датасет: 30 туристических заявок.



Baseline: 14/30 полностью правильных заявок.

Zero-shot: 20/30.

Few-shot: 15/30.



Время обработки тестовой заявки: 3.12 сек.

Входные токены: 219.

Выходные токены: 57.



Результаты получены в учебном эксперименте.



\## 8. Важно



Модель Qwen не хранится в GitHub-репозитории.

Каждый пользователь должен отдельно установить Ollama

и скачать модель qwen2.5:3b.



ИИ работает локально на компьютере пользователя.

Для обработки заявки не требуется облачный API.
